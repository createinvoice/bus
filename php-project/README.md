# বাসগো (BusGo) - বাংলা বাস রিজার্ভেশন ম্যানেজমেন্ট সিস্টেম
## Production-Ready PHP 8+ / MySQL Web Application

বাসগো একটি সম্পূর্ণ স্বয়ংসম্পূর্ণ, দ্রুতগতির ও বাংলা ভাষার বাস টিকিট রিজার্ভেশন এবং কালেকশন ম্যানেজমেন্ট সিস্টেম। এটি বিশেষ করে Namecheap Shared Hosting, cPanel বা যেকোনো সাধারণ Apache + PHP 8+ + MySQL হোস্টিংয়ে কোনো Node.js, Composer, Laravel বা জটিল কনফিগারেশন ছাড়াই চালানোর জন্য তৈরি করা হয়েছে।

---

## 🚀 প্রধান সুবিধাসমূহ
1. **সম্পূর্ণ বাংলা ইউজার ইন্টারফেস** (Noto Sans Bengali ফন্ট সহ)।
2. **ভূমিকাভিত্তিক নিয়ন্ত্রণ (RBAC):**
   - **সুপার অ্যাডমিন:** ড্যাশবোর্ড, বাস, রুট, ট্রিপ, ব্যবহারকারী, বাস বরাদ্দ, কালেকশন ও রিপোর্ট ম্যানেজমেন্ট।
   - **রিজার্ভেশন অপারেটর / স্টাফ:** শুধু নিজের অ্যাসাইন করা বাস ও ট্রিপের টিকিট বিক্রি, অগ্রিম গ্রহণ, বাকি আদায় ও টিকিট প্রিন্ট।
3. **২x২ বাস সিট লেআউট:** রিয়েল-টাইম সিট নির্বাচন, বুকড সিট লক এবং ডুপ্লিকেট বুকিং প্রতিরোধ।
4. **অগ্রিম ও বাকি টাকা আদায় (Due Collection):** স্বয়ংক্রিয় বাকি হিসাব ও প্রতিটি লেনদেনের আলাদা হিস্ট্রি সংরক্ষণ।
5. **প্রিন্ট-ফ্রেন্ডলি টিকিট:** সাধারণ A4 সাইজ এবং পোর্টেবল Thermal POS (80mm/58mm) স্লিপ ভিউ।
6. **ডেইলি ক্লোজিং ও রিপোর্ট:** কোন অপারেটর বা বাসে কত কালেকশন হয়েছে তার তারিখভিত্তিক দৈনিক ক্লোজিং।

## 🛠️ cPanel / Namecheap Shared Hosting ইনস্টলেশন নির্দেশিকা

### ধাপ ১: cPanel-এ লগইন করুন
আপনার হোস্টিং প্রোভাইডার থেকে প্রাপ্ত তথ্য দিয়ে cPanel-এ প্রবেশ করুন।

### ধাপ ২: MySQL ডেটাবেস ও ব্যবহারকারী তৈরি করুন
1. cPanel থেকে **MySQL® Database Wizard** অপশনে যান।
2. নতুন ডেটাবেসের নাম দিন (যেমন: `cpaneluser_busgo`)।
3. নতুন ডেটাবেস ব্যবহারকারী (Username) ও শক্তিশালী পাসওয়ার্ড দিন।
4. ব্যবহারকারীকে ডেটাবেসের **ALL PRIVILEGES** টিক দিয়ে যুক্ত করুন।
5. ডেটাবেস নাম, ব্যবহারকারী নাম ও পাসওয়ার্ড নোট করে রাখুন।

### ধাপ ৩: phpMyAdmin-এ database.sql ইমপোর্ট করুন
1. cPanel-এর **phpMyAdmin** খুলুন।
2. বাম পাশ থেকে আপনার নতুন ডেটাবেসটি সিলেক্ট করুন।
3. উপরের মেন্যু থেকে **Import** ট্যাবে ক্লিক করুন।
4. প্রজেক্টের সাথে থাকা `database.sql` ফাইলটি নির্বাচন করুন এবং **Go / Import** চাপুন।

### ধাপ ৪: ফাইল আপলোড করুন
1. cPanel থেকে **File Manager** খুলুন।
2. `public_html` ফোল্ডারে প্রবেশ করুন (অথবা সাব-ডোমেইনের ফোল্ডারে)।
3. প্রজেক্টের সমস্ত ফাইল ও ফোল্ডার আপলোড করে Extract করুন।

### ধাপ ৫: includes/config.php কনফিগার করুন
1. File Manager-এ `includes/config.php` ফাইলটি Edit করুন।
2. আপনার তৈরি করা ডেটাবেসের তথ্য দিন:
```php
define('DB_HOST', 'localhost');
define('DB_NAME', 'আপনার_ডেটাবেস_নাম');
define('DB_USER', 'আপনার_ডেটাবেস_ইউজার');
define('DB_PASS', 'আপনার_ডেটাবেস_পাসওয়ার্ড');
```
3. ফাইলটি সংরক্ষণ (Save Changes) করুন।

## 🔑 ডেমো লগইন তথ্য

### ১. সুপার অ্যাডমিন (Super Admin)
* **লগইন ইউআরএল:** `https://yourdomain.com/login.php`
* **ইউজারনেম:** `admin`
* **পাসওয়ার্ড:** `Admin@12345`

### ২. রিজার্ভেশন ইউজার / কাউন্টার মাস্টার (Operator)
* **ইউজারনেম:** `operator1`
* **পাসওয়ার্ড:** `123456`
*(মোহাম্মদ রহিম - সোনার বাংলা বাসের জন্য অ্যাসাইন করা)*

> ⚠️ **জরুরি সতর্কতা:** সিস্টেমে প্রথমবার লগইন করার পর অবশ্যই প্রোফাইল পেজে (`profile.php`) গিয়ে অ্যাডমিন ও ডেমো ব্যবহারকারীদের পাসওয়ার্ড পরিবর্তন করে নিন।

## 📋 প্রজেক্ট ব্যবহারের প্রথমিক কর্মপদ্ধতি (Workflow)
1. **অ্যাডমিন লগইন:** প্রথমে `admin` অ্যাকাউন্টে প্রবেশ করুন।
2. **বাস ও রুট তৈরি:**
   - **রুট:** `admin/routes.php` থেকে আপনার রুট যুক্ত করুন (যেমন: ঢাকা → কুষ্টিয়া)।
   - **বাস:** `admin/buses.php` থেকে বাস ও মোট সিট যুক্ত করুন।
3. **ট্রিপ তৈরি:** `admin/trips.php` থেকে বাসের জন্য তারিখ, সময় ও সিট ভাড়া দিয়ে ট্রিপ তৈরি করুন।
4. **অপারেটর তৈরি ও বরাদ্দ:** `admin/users.php` থেকে কাউন্টার মাস্টারের অ্যাকাউন্ট তৈরি করে `admin/assignments.php` থেকে তার জন্য নির্দিষ্ট বাস বা ট্রিপ অ্যাসাইন করুন।
5. **টিকিট বিক্রি:** অপারেটর তার ড্যাশবোর্ডে লগইন করে নির্দিষ্ট ট্রিপে সিট সিলেক্ট করবে, যাত্রীর অগ্রিম টাকা জমা নিয়ে বুকিং কনফার্ম করবে এবং সাথে সাথে প্রিন্ট বাটন চেপে টিকিট প্রিন্ট করতে পারবে।
6. **বাকি আদায় ও ক্লোজিং:** যাত্রা শুরুর আগে বাকি টাকা কাউন্টারে নিয়ে 'বাকি টাকা গ্রহণ করুন' বাটনে ক্লিক করলেই হিসাব সমন্বয় হয়ে যাবে এবং অ্যাডমিন দিনশেষে ডেইলি ক্লোজিং রিপোর্টে সার্বিক কালেকশন দেখতে পারবে।
